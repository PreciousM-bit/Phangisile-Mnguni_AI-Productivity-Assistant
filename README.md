# AI Workplace Productivity Assistant

A modern, responsive SaaS web application that helps professionals automate daily work tasks using AI. Built with a clean dashboard UI, sidebar navigation, and 5 core AI-powered tools.

## ✨ Features

- **Smart Email Generator**  
  Generate professional emails based on purpose, tone, and audience. Structured prompt engineering ensures clear, on-brand output.
  
- **Meeting Notes Summarizer**  
  Paste meeting transcripts and get Key Points, Action Items, and Deadlines instantly.

- **AI Task Planner**  
  Input your to-do list and get tasks prioritized using the Eisenhower Matrix with suggested time blocks.

- **AI Research Assistant**  
  Get executive summaries, key insights, and business implications for any research topic.

- **AI Chatbot Interface**  
  Real-time assistant for workplace questions, planning, and writing help.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Tailwind CSS, Vanilla JavaScript
- **Design**: Responsive, Card-based SaaS UI
- **AI**: Mock responses included. Ready to connect to OpenAI, Gemini, or Claude API
